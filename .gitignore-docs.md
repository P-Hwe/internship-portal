# 📋 .gitignore - Guia de Uso

## 🎯 Qual arquivo usar?

| Arquivo | Quando Usar | Branch |
|---------|-------------|--------|
| `.gitignore` | **Padrão atual** - Desenvolvimento local | `feature/*` |
| `.gitignore.dev` | Homologação (hml) | `hml` |
| `.gitignore.prod` | **Produção** - Nunca commitar em main | `prod` |

---

## 📁 Arquivos de .gitignore

### 1. `.gitignore` (Padrão)
- ✅ Para desenvolvimento local
- ✅ Permite scripts de seed/migração
- ❌ NÃO para produção

### 2. `.gitignore.dev`
- ✅ Para ambiente de homologação (hml)
- ✅ Mesma permissão que o padrão
- ❌ NÃO para produção

### 3. `.gitignore.prod`
- ✅ **Para produção**
- ❌ **NÃO deve ter scripts de seed/migração**
- ❌ **NÃO deve ter arquivos de teste**

---

## 🔒 O que NÃO commitar em PRODUÇÃO

### Scripts de Desenvolvimento
```
❌ database/seed.php          # Seed local
❌ database/.htaccess          # Configuração local
❌ scripts/seed-local.sh       # Script de seed
❌ scripts/testar-email.php    # Testes de email
❌ scripts/check-quality.sh    # Check de qualidade
❌ scripts/fix-style.sh        # Correção de estilo
```

### Arquivos de Teste
```
❌ tests/                      # Testes unitários
❌ test/                       # Testes funcionais
❌ public/uploads/teste/*      # Uploads de teste
```

### Dados Sensíveis
```
❌ .env                        # Variáveis de ambiente
❌ storage/mail/*              # Emails gerados
❌ storage/termos/*            # Termos aceitos
❌ public/uploads/*            # Uploads variados
```

---

## ✅ O que DEVE estar em PRODUÇÃO

### Scripts Essenciais
```
✅ database/migrate.php        # Migrações principais
✅ database/schema.php         # Esquema do banco
✅ database/mysql.sql          # SQL do banco
✅ database/README-SEED.md     # Documentação
```

### Arquivos de Configuração
```
✅ .env.prod                    # Configuração de produção
✅ config.php                  # Configurações
```

---

## 🔄 Como Atualizar para Produção

### Passo 1: Copiar .gitignore.prod
```bash
cp .gitignore.prod .gitignore
```

### Passo 2: Remover arquivos proibidos
```bash
# Remove scripts de seed/migração local
rm database/seed.php
rm database/.htaccess
rm scripts/seed-local.sh
rm scripts/testar-email.php
```

### Passo 3: Commitar
```bash
git add .gitignore
git commit -m "chore: atualiza .gitignore para produção"
```

## 📊 Resumo de Segurança

| Tipo | Main (Prod) | Feature (Dev) | hml (Homolog) |
|------|-------------|----------------|----------------|
| Scripts seed | ❌ Bloqueado | ✅ Permitido | ✅ Permitido |
| Testes | ❌ Bloqueado | ✅ Permitido | ✅ Permitido |
| .env | ❌ Bloqueado | ✅ Permitido | ✅ Permitido |
| Logs | ❌ Bloqueado | ✅ Permitido | ✅ Permitido |

---

## ⚠️ Importante

- **NUNCA** commitar `.gitignore.prod` em `main`
- **SEMPRE** verificar antes de commitar scripts de desenvolvimento
- **USE** `.gitignore.dev` para homologação
- **USE** `.gitignore.prod` apenas para produção
